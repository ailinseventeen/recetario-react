# Mi Recetario (React + Vite)

    npm install
    npm run dev      # desarrollo
    npm run build    # producción (carpeta dist/)

- Recetas: `src/data/recipes.js` (formato `[cantidad, unidad, nombre]` por ingrediente)
- Componentes: `src/components/`
- Estilos y tema claro/oscuro: `src/styles.css`
